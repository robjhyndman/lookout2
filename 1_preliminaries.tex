\section{Preliminaries}\label{sec:prelim}
%------------------------------------------------------
While everyone knows what an anomaly is, there is no broadly accepted definition for it. \citet{hawkins1980identification} defines an anomaly/outlier as \textit{an observation which deviates so much from other observations as to arouse suspicion it was  generated by a different mechanism.} \citet{barnett1994outliers} define an anomaly/outlier as \textit{an observation (or a subset of observations) which appears to be inconsistent with the remainder of that set of data.} Both these definitions agree that anomalies are rare and different from other observations. Given a set of points $\bm{x}_{i} \in \mathbb{R}^d$ for $i \in \{1, \ldots N\}$, we consider a point $\bm{x}_i$ to be anomalous if it has low conditional probability, i.e., for small $\epsilon$,
\begin{equation}
    \mathbb{P}(\bm{x}_{i}|\bm{x}_{1}, \ldots, \bm{x}_{i-1}, \bm{x}_{i+1}, \ldots, \bm{x}_{N}) \leq \epsilon \, . 
\end{equation}
