\section{Introduction} \label{sec:intro}
% ------------------------------------------------------------

Anomaly detection is used in many application domains such as credit card fraud and scam detection \citep{kolupuri2025scams}.  \cite{lookout} proposed the \textit{lookout} algorithm for anomaly detection using a kernel density estimate with bandwidth based on persistence homology. Anomalies are identified by fitting a Generalized Pareto Distribution (GPD) to the negative logarithm of the smallest leave-one-out kernel density estimates, and declaring points with low GPD probabilities as anomalies.

In this paper, we explore some of the properties of the lookout algorithm, particularly the choice of bandwidth and what that choice implies for the kernel density estimates it produces. The bandwidth was originally expressed in terms of the death diameters of a Vietoris-Rips filtration, but those death diameters are the edge lengths of the Euclidean minimum spanning tree of the data, and we work with the minimum spanning tree in this paper. This allows us to analyse the asymptotic properties of the algorithm, and to propose a modified lookout algorithm that takes its bandwidth from a different feature of the same set of edge lengths. The modified algorithm improves the performance and robustness of the original algorithm, under a broader range of conditions.

First we introduce some background material, before describing both the original lookout algorithm, and our proposed modifications.

\subsection{Anomalies and surprisals}

There is no broadly accepted definition for an anomaly. \citet{hawkins1980identification} defines an anomaly or outlier as \textit{an observation which deviates so much from other observations as to arouse suspicion it was generated by a different mechanism.} \citet{Barnett1978} define an anomaly or outlier as \textit{an observation (or a subset of observations) which appears to be inconsistent with the remainder of that set of data.} Both these definitions agree that anomalies are rare and different from other observations. That can be applied by fitting some (conditional) probability distribution to the set of observations, and considering whether each observation is a likely random draw from the probability distribution. \citet{surprisals} proposed a formalization of this concept, which we state in the following definition. Throughout, $f$ is a probability density function on $\R^m$ with respect to Lebesgue measure. It is the density against which the observations are judged. We do not assume that every observation is a draw from $f$; the anomalies are the observations that are unlikely under $f$.

\begin{defn}[Anomalies]
  Given a set of observations $\bm{y}_{i} \in \R^m$ for $i \in \{1, \dots, n\}$, and a probability density function $f$, we define observation $\bm{y}_i$ as anomalous if
  \begin{equation}
    \P(f(\bm{Y}) \le f(\bm{y}_{i})) < \alpha,
  \end{equation}
  where $\bm{Y}$ is a random vector with density $f$, and $\alpha>0$ is a chosen threshold.
\end{defn}

\begin{defn}[Surprisals]
  Given a probability density function $f$, the \emph{surprisal} of an observation $\bm{y}$ with respect to $f$ is defined as $-\log f(\bm{y})$.
\end{defn}
These are better known as  ``log scores'' in statistics \citep{Good1952-zw}, but we prefer the term ``surprisals'' from information theory \citep{Stone2022}, as it provides a measure of how surprising an observation is, given the probability density function $f$. Specifically, it takes large values for observations that are unlikely under $f$.

Let $S = -\log f(\bm{Y})$ be the random variable representing the surprisal of a random vector $\bm{Y}$ with density $f$, and let $G(s) = \P(S\le s)$ be its distribution function. Then the surprisal probability of observation $\bm{y}_i$ is given by
$$p_i = 1 - G(s_i^-),$$
where $s_i = -\log f (\bm{y}_i)$, and $G(s_i^-) = \lim_{t \uparrow s_i} G(t)$ is the left limit of $G$ at $s_i$. An observation is an anomaly if and only if $p_i < \alpha$.

\subsection{Extreme value theory}

The lookout algorithm determines which surprisals are unusually large by using a peaks-over-threshold approach \citep{Pickands1975,coles2001introduction}, and fitting a Generalized Pareto distribution (GPD) to the upper tail of the observed surprisals. That is,
\begin{equation}\label{eq:POT4}
  \P(S \le s \mid S > u) = \frac{G(s) - G(u)}{1 - G(u)}
  \approx 1 - (1 + \xi (s-u)/\sigma_u)^{-1/\xi}, \qquad s > u, \quad 1 + \xi (s-u)/\sigma_u > 0,
\end{equation}
where $u$ is a threshold chosen to be large enough that the conditional distribution of the excess $S-u$ over the threshold is well approximated by a GPD, $\sigma_u > 0$ is a scale parameter depending on the threshold, and $\xi \in \R$ is a shape parameter that does not. The case $\xi = 0$ is read as the limiting case $1 - \exp(-(s-u)/\sigma_u)$.

The distribution in \eqref{eq:POT4} is unbounded above when $\xi \ge 0$, and has finite upper endpoint $u + \sigma_u/|\xi|$ when $\xi < 0$, so a quantity that is bounded above cannot have a positive shape parameter. We use this in \cref{sec:modified} to constrain the fitted GPD.

\subsection{Kernel density estimation}

Given a set of observations $\bm{y}_{i} \in \R^m$ for $i \in \{1, \dots, n\}$, a kernel density estimate is defined as \citep{chacon2018multivariate}
\begin{equation}\label{eq:mkde}
  \hat{f}(\bm{y}) = \frac{1}{n} \sum_{i=1}^n |\bm{H}|^{-1/2} K\big(\bm{H}^{-1/2}(\bm{y} - \bm{y}_i)\big),
\end{equation}
where $K$ is a kernel function and $\bm{H}$ is a symmetric $m\times m$ positive-definite bandwidth matrix. When the observations are $n$ independent draws from $f$, the accuracy of $\hat{f}$ is conventionally measured by the mean integrated squared error (MISE),
\begin{equation}\label{eq:mise}
  \text{MISE}(\hat{f}) = \E\left[\int \big(\hat{f}(\bm{u}) - f(\bm{u})\big)^2 d\bm{u}\right],
\end{equation}
where the expectation is taken over that sample, and we say that $\hat{f}$ is a \emph{consistent estimator} of $f$ if $\text{MISE}(\hat{f})\rightarrow 0$ as $n\rightarrow\infty$. Consistency holds under the following conditions on the density, the kernel and the bandwidth matrix \citep[][pp.~31--37]{chacon2018multivariate}.

\begin{description}
  \item[A1] The density function $f$ is square integrable and twice differentiable, with all of its second-order partial derivatives bounded, continuous and square integrable.
  \item[A2] The kernel $K$ is a square-integrable, spherically symmetric function on $\R^m$ that satisfies\break $\int K(\bm{u})d\bm{u} = 1$, $\int \bm{u} K(\bm{u})d\bm{u} = \bm{0}$ and $\int \bm{u}\bm{u}^T K(\bm{u})d\bm{u} = \mu_2(K)\bm{I}_m$ for some $\mu_2(K) > 0$.
  \item[A3] The bandwidth matrix $\bm{H}$ is a sequence of symmetric positive-definite matrices such that\break $\bm{H}\rightarrow \bm{O}$ and $n|\bm{H}|^{1/2} \rightarrow \infty$ as $n\rightarrow\infty$.
\end{description}

We consider matrices of the form $\bm{H} = a h_n^2 \bm{I}_m$ for a fixed constant $a>0$, where $h_n\in\R$ is a length scale computed from the sample $\{\bm{y}_1,\dots,\bm{y}_n\}$. The constant $a$ determines the interpretation of $h_n$. With $a = m+4$, $h_n$ is the per-coordinate standard deviation of the spherically symmetric Epanechnikov kernel. Then $|\bm{H}|^{1/2}=a^{m/2}h_n^m$, so the two requirements of A3 reduce to $h_n \rightarrow 0$ and $nh_n^m \rightarrow \infty$, which we take as the definition of an admissible bandwidth.

\begin{defn}[Admissible bandwidth]\label{def:admissible_bandwidth}
  We say that $h_n$ is an \emph{admissible bandwidth} for samples in $\R^m$ if $h_n\rightarrow 0$ and $nh_n^m\rightarrow \infty$ as $n\rightarrow\infty$ in probability.
\end{defn}

\subsection{The lookout algorithm for anomaly detection}

The \textit{lookout} algorithm of \cite{lookout}, as implemented in the \texttt{lookout} package, has four inputs: the dataset $\{\bm{y}_1,\dots,\bm{y}_n\}$, where each $\bm{y}_i \in \R^m$; a parameter $\beta \in (0,1)$ such that the Generalized Pareto Distribution (GPD) is fitted to the largest $1-\beta$ of the surprisals, with $\beta = 0.9$ following \citet{bommier2014peaks}; a parameter $\alpha \in (0,1)$ signifying the cut-off threshold for determining an anomaly; and a logical variable \textit{unitize} indicating whether to scale the data. We briefly outline the steps below.

\begin{algorithm}
  \caption{Lookout algorithm}\label{alg:lookout}
  \begin{algorithmic}[1]
    \Require Data $\{\bm{y}_1, \dots, \bm{y}_n\}$, proportion $\beta \in (0,1)$, threshold $\alpha \in (0,1)$, \emph{unitize} $\in \{\text{True}, \text{False}\}$.
    \State If \textit{unitize}, scale the data to lie in the unit cube in $\R^m$.
    \State Compute the persistence homology barcode of the (possibly scaled) data cloud for dimension zero using the Vietoris-Rips diameter \citep{ghrist2008barcodes}.
    \State From the barcode, obtain the ordered finite death diameters $\{d_i\}_{i = 1}^{n-1}$ for connected components, and their successive differences $\Delta d_i = d_{i+1} - d_i$.
    \State Let $d_* = d_{i_*}$ where $i_* = \text{arg\! max} \{\Delta d_i\}_{i=1}^{n-2}$; that is, $d_*$ is the diameter corresponding to the lower point of the maximum $\Delta d_i$.\footnotemark
    \State Compute the kernel density estimates at the observations: $f_i = \hat{f}(\bm{y}_i)$, $i=1,\dots,n$, where $\hat{f}$ is given by \eqref{eq:mkde} with the kernel $K(\bm{u}) = \frac{m+2}{b_m}(1 - \|\bm{u}\|^2/5)_+$, $b_m$ being the volume of the unit ball in $\R^m$, and $\bm{H} = d_*^2\bm{I}_m$, so that the kernel has support radius $\sqrt5\,d_*$.\footnotemark
    \State Compute the leave-one-out kde values $f_{-i} = \frac{1}{n-1} \big( n f_i - |\bm{H}|^{-1/2} K(\bm{0}) \big)$ for $i=1,\dots,n$.
    \State Fit a GPD to the largest $1-\beta$ of the surprisals $\{-\log f_i\}_{i=1}^n$, obtaining estimates of the location, scale and shape parameters $(\mu, \sigma, \xi)$.
    \State Calculate the probability of each observation by applying the estimated GPD to the leave-one-out kde values: $p_i = (1-\beta)\big(1 - \hat{F}(-\log f_{-i})\big)$, where $\hat{F}$ is the distribution function of the fitted GPD.
    \State If $p_i < \alpha$, declare $\bm{y}_i$ anomalous.
  \end{algorithmic}
\end{algorithm}

\footnotetext{From version 0.1.4 of the \texttt{lookout} package, the search in step 4 is restricted to the death diameters at or above their median, so that a large gap among the shortest diameters is not chosen. The comparisons in \cref{sec:experiments} use this restricted rule.}
\addtocounter{footnote}{1}
\footnotetext{Equation (5) of \citet{lookout} gives the bandwidth matrix as $d_*^{2/m}\bm{I}_m$; the released implementation uses $d_*^2\bm{I}_m$ in every dimension, and we describe the implementation. The comparisons in \cref{sec:experiments} use $\bm{H}=(m+4)d_*^2\bm{I}_m$ with the kernel of \cref{alg:modifiedlookout} for both versions, so that $d_*$ plays the role of $h_n$.}

The lookout algorithm provides density-based anomaly detection, where anomalies are identified as points with low density in the space of the data. If there are no true anomalies in the data, the algorithm should identify a proportion $\alpha$ of the data as false positive ``anomalies''.

Steps 2--4 of \cref{alg:lookout} can be expressed in terms of the Euclidean minimum spanning tree $T$ of the data. Components of the Vietoris-Rips complex merge when the shortest edge between them appears, which is Kruskal's algorithm, so the merges occur along the edges of $T$. The finite death diameters $d_1 \le \cdots \le d_{n-1}$ are therefore the ordered edge lengths $e_{(1)} \le \cdots \le e_{(n-1)}$ of $T$ \citep[Remark 1]{AdamsPHdim}, and also the merge heights of the single linkage dendrogram \citep{Gower1969}. In the rest of the paper we use the tree rather than the filtration, so that we can apply the limit theory for minimum spanning trees.

While \citet{lookout} demonstrated excellent results in applying their algorithm to a variety of simulated and real datasets, we see several potential areas for improvement that we aim to address in this paper. First, elements of the algorithm are not robust to outliers, including the min-max scaling, and the use of the largest gap in the Rips death diameters (equivalently, edge lengths). Second, the diagonal bandwidth matrix $\bm{H}$ does not account for correlations between variables, which can lead to suboptimal performance if the data have strong correlations. Third, it is not obvious that this bandwidth matrix choice has the right order, or that it shrinks to zero at all, particularly for distributions with heavy tails. Finally, the GPD estimation made minimal assumptions about the distribution of the surprisal values, but we know that these are bounded above and below, and that fact can be used to improve the estimated GPD.

\cref{sec:mst} defines the bandwidth we use, an upper quantile $e_{(\gamma(n-1))}$ of the edge lengths, and establishes its order: $n^{1/m}e_{(\gamma(n-1))}$ converges in probability to a constant, for any density. We also give a heavy-tailed distribution for which the longest edges, among which the original choice $h_n=d_*$ typically lies, grow without bound.

\citet{Crackle} call this behaviour crackle. They studied the persistent homology of the union of unit balls centred on iid samples from various distributions, and showed that samples from heavy-tailed distributions produce isolated points at increasing distances from the origin, whereas Gaussian samples do not. Our counterexample is a direct calculation of the same effect for the edge lengths of the minimum spanning tree.

\subsection{The modified lookout algorithm}

As a result of these considerations, we propose three modifications to the lookout algorithm, described in detail in \cref{sec:modified}.

\begin{enumerate}
  \item Rather than use a max-min scaling of the data, we standardize the data using a robust covariance estimator. That is, we scale and rotate the data to ensure that the covariance matrix of the transformed data is approximately the identity matrix. This ensures that the data have zero pairwise correlations, which leads to more efficient kernel density estimates. It also leads to each variable having approximately unit variance, which provides a more robust scaling than min-max scaling.
  \item Rather than using the lower point of the largest gap in the minimum spanning tree edge lengths, we use an upper quantile of those edge lengths. This avoids the problem that a few anomalies at the top of the edge length distribution can determine the largest gap and hence the bandwidth. It also gives the bandwidth the correct order, $n^{-1/m}$, for any density.
  \item The estimated GPD shape parameter is constrained to be non-positive, which improves the stability of the GPD fitting. This is justified by noting that the kernel density estimates are bounded away from zero, so the surprisals are bounded above and the fitted GPD cannot have a positive shape parameter.
\end{enumerate}

Note that we do not need to estimate the density of the underlying distribution directly. Instead, we can estimate the density of a transformation of the data, and identify anomalies in the transformed space. Hence, there is no need to undo the scaling or rotation.

\subsection{Outline of the paper}

The remainder of this paper is organized as follows. In \cref{sec:mst}, we define the bandwidth as a quantile of the edge lengths of the Euclidean minimum spanning tree, and relate it to existing minimum spanning tree and nearest-neighbour methods. We also establish the order of that bandwidth and examine what it implies for the kernel density estimates it produces. In \cref{sec:modified}, we propose a modified lookout algorithm that improves performance and robustness under a broader range of conditions. In \cref{sec:experiments}, we report seven simulation experiments, comparing the modified algorithm first with the original lookout and then with four other anomaly detection methods. \cref{sec:applications} applies both versions to two real datasets. Finally, in \cref{sec:conclusion}, we summarize our results and discuss future work.
