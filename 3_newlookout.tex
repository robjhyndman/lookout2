The lookout2 algorithm identifies anomalies by first transforming the data to a distribution with approximate normal marginals and zero pairwise correlations. Then it estimates the density of the transformed data using a multivariate kernel density estimator with a bandwidth matrix $\bm{H}$, where $\bm{H}$ is chosen to be a function of the Rips death diameters computed from the transformed data.

\subsection{Normalization}

First, we transform each variable using Yeo-Johnson transformations \citep{yj00} so that the marginal distributions are closer to normal. A Yeo-Johnson transformation can be written as
\begin{equation}\label{eq:yj}
  f(x) =
  \begin{cases}
    ((x+1)^\lambda-1)/\lambda                     & \text{if }\lambda \neq 0, x \geq 0 \\
    \log(x + 1)                                   & \text{if }\lambda = 0, x \geq 0    \\
    -((-x + 1)^{(2-\lambda)} - 1) / (2 - \lambda) & \text{if }\lambda \neq 2, x < 0    \\
    -\log(-x + 1)                                 & \text{if }\lambda = 2, x < 0
  \end{cases}
\end{equation}
where $\lambda$ is a parameter that can be estimated by minimizing the Kullback-Leibler divergence between the transformed data and a normal distribution. In principle, $\lambda$ can be any real number, but we restrict it to lie in the interval $[0,1]$ to avoid overly aggressive transformations (and thereby disguising anomalies as legitimate observations).

We transform $x_{i,j}$ to $x_{i,j}^* = f_j(x_{i,j}) - m_j$ where ${f}_j$ is the optimal Yeo-Johnson transformation for the $j$th variable, and $m_j$ is the median of $f_j(x_{1,j}),\dots,f_j(x_{n,j})$. (Medians are used because the purpose of the exercise is anomaly detection, and we want to avoid the influence of outliers.) This is implemented using the bestNormalize package in R \citep{bestNormalize,bestNormalizeR}.

\subsection{Standardization}

Then we can rotate the data to ensure zero pairwise correlations. Let $\hat{\bm{\Sigma}}$ denote the orthogonalized Gnanadesikan-Kettenring estimator of the covariance matrix of $\bm{X}^{*}$ \citep{Maronna2002-qn}, and let its eigendecomposition be given by $\hat{\bm{\Sigma}}^{-1} = \bm{U}' \bm{\Lambda} \bm{U}$. Then, the data can be scaled by $\bm{U}$, giving $\bm{Z} = \bm{U}\bm{X}^*$, so that the covariance matrix of the scaled data $\bm{Z}$ is (approximately) the identity matrix. This can be thought of as both scaling and rotating the data; it is the multivariate equivalent of computing robust z-scores.

\subsection{Rips diameters}

The Rips death diameters are computed from the scaled and rotated data $\bm{Z}$. Let $d_1,\dots,d_N$ denote the (ordered) Rips death diameters computed from the sample $\bm{z}_1,\dots,\bm{z}_N$, and let $d^*$ denote the 0.9 sample quantile \citep{HF96} computed from $\{d_1,\dots,d_N\}$.

\subsection{Bandwidth selection}

A kernel density estimator is applied to the scaled data $\{\bm{z}_1,\dots,\bm{z}_N\}$ using the bandwidth matrix
$$\bm{H} = d^{*2/p}\bm{I},$$
where $p$ is the dimension of the data.
