\section{Lookout algorithm v2}\label{sec:modified}

In light of the preceding theoretical considerations, we propose three modifications to the lookout algorithm, described in this section.

\subsection{Standardization}

The \emph{minimum covariance determinant} estimator provides a robust estimate of $\bm{\Sigma}$, the covariance matrix of $\{\bm{y}_1,\dots,\bm{y}_n\}$, by searching for the subsample of a given size whose sample covariance matrix has the smallest determinant \citep{rousseeuw1999fast}. We take that subsample to be of size $0.9n$. This has a lower breakdown point than the usual choice of $n/2$, but anomalies are assumed to be rare, and the larger subsample gives a more efficient estimate of $\bm{\Sigma}$ for the non-anomalous observations. Let
\begin{equation}\label{eq:mcd}
  \hat{\bm{\Sigma}}^{-1} = \bm{U}' \bm{U}
\end{equation}
denote the Cholesky decomposition of its inverse. Then, the data can be scaled by $\bm{U}$, giving $\bm{z}_i = \bm{U}(\bm{y}_i - \bm{m})$, where $\bm{m}$ is the vector of medians of $\{\bm{y}_1,\dots,\bm{y}_n\}$. The covariance matrix of the scaled data $\{\bm{z}_1,\dots,\bm{z}_n\}$ is (approximately) the identity matrix. This can be thought of as both scaling and rotating the data; it is the multivariate equivalent of computing robust z-scores.

We prefer this to the min-max scaling used in the original lookout algorithm because it is robust to outliers and removes the correlations between variables. The kernel in \cref{alg:modifiedlookout} also has a covariance matrix that is a multiple of the identity, so the kernel is aligned with the standardized data; alignment is not necessary, but it improves the efficiency of the kernel density estimate \citep{chacon2018multivariate}.

\subsection{Bandwidth matrix selection}

Let $e_{(1)} \le \cdots \le e_{(n-1)}$ denote the ordered edge lengths of the Euclidean minimum spanning tree of the standardized data $\bm{z}_1,\dots,\bm{z}_n$, and let $h_n = e_{(\lceil\gamma(n-1)\rceil)}$ be the bandwidth of \cref{def:mstbw}. The kernel density estimate is computed from the standardized data with the bandwidth matrix \eqref{eq:Hmst}, so that by \cref{prop:critical} the number of observations inside the kernel window is bounded as $n\to\infty$, which \cref{sec:whynotmise} argues is appropriate for anomaly detection. When the proportion of anomalies is small, we expect this estimate to be close to the density of the non-anomalous observations. An equivalent estimate for the original data would use $\bm{H} = (m+4)h_n^2\hat{\bm{\Sigma}}$; we work with the standardized data throughout.

\subsection{Bounds for kernel density estimates}

The surprisals to which the GPD is fitted are bounded, which constrains the shape parameter.

\begin{remark}\label{lemma:boundsforkde}
  Let $K$ be a kernel with $0\le K(\bm{u})\le K(\bm{0})=K_0$ for all $\bm{u}$, and let $\hat{f}$ be the estimate \eqref{eq:mkde} with bandwidth matrix $\bm{H}$. The term $i=j$ of the sum contributes $|\bm{H}|^{-1/2}K_0/n$ and no term exceeds that, so
  $$
  \frac{K_0|\bm{H}|^{-1/2}}{n} \le \hat{f}(\bm{y}_j) \le K_0|\bm{H}|^{-1/2}, \qquad j = 1,\dots,n,
  $$
  and the surprisals $-\log\hat{f}(\bm{y}_j)$ lie in the interval $[\tfrac12\log|\bm{H}| - \log K_0,\ \tfrac12\log|\bm{H}| + \log(n/K_0)]$, whose endpoints depend on the sample only through $\bm{H}$.
\end{remark}

For the Epanechnikov kernel $K(\bm{u}) = \frac{m+2}{2b_m} ( 1 - \|\bm{u}\|^2 )_{+}$, where $u_+ = \max(0, u)$, $K_0 = (m+2)/(2b_m)$.

A GPD with non-negative shape parameter has unbounded support, so when we fit the GPD to the largest $1-\beta$ of $\{-\log\hat{f}(\bm{y}_j)\}_{j=1}^n$ we constrain its shape parameter to be non-positive, which improves the stability of the fit.

The GPD is fitted under two approximations. The surprisals are computed from $\hat{f}$ rather than from $f$, and they are evaluated at the observations rather than at independent draws, so the values to which the GPD is fitted are neither mutually independent nor distributed exactly as $S$ in \cref{sec:intro}.

\subsection{Modified lookout algorithm}

\cref{alg:modifiedlookout} summarises the modified algorithm.

\begin{algorithm}
  \caption{Modified lookout algorithm}\label{alg:modifiedlookout}
  \begin{algorithmic}[1]
    \Require Data $\{\bm{y}_1, \dots, \bm{y}_n\}$, proportion $\beta \in (0,1)$, threshold $\alpha \in (0,1)$, and quantile level $\gamma \in (0,1)$.
    \State Optional scaling: calculate the minimum covariance determinant estimate $\hat{\bm{\Sigma}}$ and the Cholesky decomposition \eqref{eq:mcd}, and centre, rotate and scale the data using $\bm{U}$, giving $\bm{z}_i = \bm{U}(\bm{y}_i - \bm{m})$ for $i = 1,\dots,n$, where $\bm{m}$ is the vector of medians of $\{\bm{y}_1,\dots,\bm{y}_n\}$.
    \State Compute the Euclidean minimum spanning tree of $\{\bm{z}_1,\dots,\bm{z}_n\}$ (set $\bm{z}_i = \bm{y}_i$ if no scaling is applied), and obtain its ordered edge lengths $e_{(1)} \le \cdots \le e_{(n-1)}$.
    \State Let $h_n = e_{(\lceil\gamma(n-1)\rceil)}$, the $\gamma$ sample quantile computed from $\{ e_{(i)} \}_{i=1}^{n-1}$.
    \State Compute the kernel density estimates at the scaled observations: $f_i = \hat{f}(\bm{z}_i)$, $i=1,\dots,n$, where $\hat{f}$ is given by \eqref{eq:mkde} applied to $\bm{z}_1,\dots,\bm{z}_n$ with the Epanechnikov kernel $K(\bm{u}) = \frac{m+2}{2b_m}(1 - \|\bm{u}\|^2)_+$ and $\bm{H} = (m+4)h_n^2\bm{I}_m$.
    \State Compute the leave-one-out kde values $f_{-i} = \frac{1}{n-1} \big( n f_i - |\bm{H}|^{-1/2} K(\bm{0}) \big)$ for $i=1,\dots,n$.
    \State Fit a Generalized Pareto Distribution (GPD) to the largest $1-\beta$ of the surprisals $\{-\log f_i\}_{i=1}^n$, constraining the shape parameter to be non-positive, obtaining estimates of the location, scale and shape parameters $(\mu, \sigma, \xi)$.
    \State Calculate the probability of each observation by applying the estimated GPD to the leave-one-out kde values: $p_i = (1-\beta)\big(1 - \hat{F}(-\log f_{-i})\big)$, where $\hat{F}$ is the distribution function of the fitted GPD.
    \State If $p_i < \alpha$, declare $\bm{y}_i$ anomalous.
  \end{algorithmic}
\end{algorithm}

As with the original lookout algorithm, the values of $p_i$ can also act as anomaly scores, with lower values indicating more anomalous points. The probability $p_i$ in step 7 is the unconditional probability of a surprisal at least as large as $-\log f_{-i}$, which is $1-\beta$ times the exceedance probability of the fitted GPD. In step 6 the implementation fits the GPD without constraint and, if the estimated shape parameter is positive, refits it with the shape parameter fixed at zero.

The default values are $\alpha = 0.01$, $\beta = 0.90$ and $\gamma = 0.98$, with scaling applied. They are used in all experiments reported here unless stated otherwise.

Step 4 evaluates \eqref{eq:mkde} at each of the $n$ observations, which costs $O(n^2)$ if the sum is taken over all pairs, and the exact sum is practical only for $n$ up to about $10^4$ (\cref{tab:timing}). For larger $n$ the implementation sums each kernel over the nearest neighbours of the observation only, between 100 and 500 of them depending on $n$. \cref{tab:bwconst} shows that the kernel support around an observation in the bulk of the data can contain many more observations than that, so the truncated sum underestimates $\hat f$ there. The observations relevant to anomaly detection have few neighbours inside the support, and their estimates are unchanged. The truncated sum is used in Experiment 2, in Experiment S2 of the online Appendix, and for the wine reviews data in \cref{sec:applications}.
